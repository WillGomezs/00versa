# Relatório de Validação — Trilha IBGE v2

Data da revisão: 06/08/2026.

## Contagens

- 19 módulos.
- 98 microlições.
- 327 questões.
- 32 questões oficiais textuais de 2019 integradas.
- 80 videoaulas, canais, coleções ou buscas temáticas.
- 39 questões no diagnóstico.
- 60 questões no simulado oficial.
- 32 questões no bloco histórico interativo.

## Verificações automáticas

- Todas as lições possuem pelo menos três questões.
- Todas as questões apontam para lições existentes.
- Todas as questões possuem cinco alternativas.
- Todos os índices de gabarito estão entre 0 e 4.
- Todas as alternativas incorretas possuem comentário.
- O diagnóstico contém somente questões existentes.
- Todas as referências de vídeo das lições existem no catálogo.
- Não há pré-requisito apontando para lição posterior.
- A distribuição do simulado oficial permanece 15 + 10 + 35.
- O progresso usa chave independente para a trilha IBGE.
- DATAPREV e ASON foram preservadas.
- Os scripts JavaScript passaram na verificação de sintaxe.
- O ZIP passou no teste de integridade.

## Limites editoriais

A validação automática verifica estrutura interna. Ela não substitui revisão acadêmica especializada. As questões oficiais de 2019 foram incorporadas com base no caderno e no gabarito definitivo fornecidos; as questões dependentes de figura não foram transcritas para evitar perda de contexto visual.

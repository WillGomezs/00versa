- 17 padrões de representação: fluxos, comparações, pilhas, grids, linhas do tempo, ciclos, endereçamento, topologias, hub, switch, AP, pacote/quadro, mapeamento OSI↔TCP/IP, rede/host, tabela de roteamento, barras de domínio e tríade CIA.

COMANDOS
- `npm run test:static` — suíte estática completa.
- `npm ci && npm test` — suíte completa com jsdom.
- `npm run checksums` — atualiza SHA256SUMS.txt.

PUBLICAÇÃO NO GITHUB PAGES
1. Extraia o ZIP.
2. Envie o conteúdo para a raiz da branch principal.
3. Em Settings > Pages, selecione publicação a partir da branch e / (root).
4. Compare SHA-256 antes de publicar.

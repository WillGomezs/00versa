ARQUIVOS PRINCIPAIS
1. index.html
   Aplicação completa, interface, estilos, dados das trilhas DATAPREV, ASON e IBGE, integração CFAQ-MOC e lógica de funcionamento.

2. cfaq-data.js
   Dados modulares da trilha CFAQ-MOC Nacional: módulos, microlições, questões, textos-base, vídeos e referências.

3. assets/cfaq/
   Imagens extraídas das questões CFAQ-MOC, sem Base64 no HTML principal.

4. README.md
   Documentação geral, conteúdo das trilhas, execução, GitHub Pages, privacidade e limitações.

5. logo.svg
   Logotipo vetorial usado na interface.

6. favicon.svg, favicon.ico, favicon-32x32.png, favicon-192x192.png e apple-touch-icon.png
   Identidade visual da aba do navegador, atalhos e dispositivos móveis.

7. site.webmanifest
   Metadados para instalação e identificação do site como aplicação web.

8. .nojekyll
   Impede que o GitHub Pages processe o projeto com Jekyll.

DOCUMENTAÇÃO E FERRAMENTAS CFAQ-MOC
16. MAPEAMENTO_CFAQ_MOC.md

17. RELATORIO_IMPORTACAO_CFAQ_MOC.md e AUDITORIA_IMPORTACAO_CFAQ_MOC.json
    Registro das questões importadas, omitidas, duplicadas, textos-base e imagens.

18. RELATORIO_VALIDACAO_CFAQ_MOC.md e RELATORIO_TESTE_FLUXO_CFAQ_MOC.md

20. fontes/Rota_Naval_original.html

21. tools/ e package.json
    Gerador, validação estrutural e teste de fluxo DOM. O npm é opcional e não é necessário para usar o site.

ARQUIVOS GERAIS
22. CHANGELOG.md
    Registro das alterações das versões IBGE e CFAQ-MOC.

23. SHA256SUMS.txt
    Resumos criptográficos para conferir a integridade dos arquivos do pacote.

PUBLICAÇÃO NO GITHUB PAGES
1. Extraia o ZIP.
2. Envie todo o conteúdo para a raiz da branch main.
3. Abra Settings > Pages.
4. Escolha Deploy from a branch, branch main e pasta /(root).
5. Salve e aguarde a publicação.

O projeto é estático, não exige npm, compilação, banco de dados ou servidor próprio.
O progresso é salvo no navegador e permanece separado por trilha.
